# flutter_ecommerce_app

## core/: Uygulama genelinde kullanılan sabitler, yardımcı fonksiyonlar ve servisleri içerir.

## models/: Kullanılan veri modellerini barındırır (örneğin ProductModel, UserModel).

## providers/: State management (örn. Provider, Riverpod) için kullanılır.

## views/: Ekranları modüler bir şekilde içerir.

## widgets/: Tekrar kullanılabilir UI bileşenlerini içerir.

## assets/: Görseller, ikonlar ve yazı tipleri burada tutulur.
